# The WhatsApp template to submit

**Submit this before the first order goes out.** Approval takes anything from a
few minutes to two working days, and until it lands every WhatsApp send fails
with Meta error `132001`.

---

## Why a template is needed at all

A business cannot send whatever it likes to a WhatsApp user. There is a 24-hour
**customer service window**, and it opens only when the *user* messages the
*business*. Inside it, free-form messages are allowed. Outside it — which is
every order Nerige will ever send, because a weaver has no reason to message
first — only a template pre-approved by Meta may be sent, and only as the
opening message of the conversation.

So a send is two stages, and the code does exactly this:

1. **One template message.** This is the only thing allowed to arrive
   unsolicited, and sending it opens the 24-hour window.
2. **Then the photographs**, one per line, as ordinary free-form messages inside
   the window that step 1 just opened.

Step 2 is legally and technically dependent on step 1 succeeding. If the
template fails, the images are not attempted — they would be rejected, and
attempting them repeatedly is what gets a number rate-limited.

---

## What to submit

In **WhatsApp Manager → Account tools → Message templates → Create template**:

| Field | Value |
| --- | --- |
| Name | `nerige_new_order` |
| Category | **Utility** |
| Language | English |

> **Category matters.** Choose Utility, not Marketing. This is a transactional
> message about an order the recipient has a commercial relationship over.
> Marketing templates are priced higher, are subject to per-user frequency caps,
> and are the ones users most often block.

### Header

None. A header image would have to be a fixed one or a variable, and neither is
right here — the photographs are the body of the job and there are up to twelve
of them.

### Body

Paste this exactly:

```
Namaste {{1}}, you have a new order from Nerige.

Order {{2}} — {{3}} pieces in total.

The photographs and codes follow in the next few messages. Please write the code shown under each photograph on that saree before you pack it.

Reply here if anything is unclear.
```

### Sample values

Meta requires examples for every variable or the submission is rejected:

| Variable | Example |
| --- | --- |
| `{{1}}` | `HDR Handlooms` |
| `{{2}}` | `ORD-000142` |
| `{{3}}` | `18` |

### Footer

```
Nerige Story
```

### Buttons

None.

## What the code sends

`src/lib/integrations/whatsapp.ts` sends exactly three body parameters, in this
order:

1. the vendor's display name
2. the order number
3. the total piece count across all lines

**Meta matches on count and order, not on name.** If you change the body text to
use a different number of variables, or reorder them, the send fails with error
`132000` and the message is unhelpfully generic. Change this file and that code
together.

---

## After approval

Set these in `.env.local` and in the deployment environment:

```bash
WHATSAPP_TEMPLATE_NAME=nerige_new_order
WHATSAPP_TEMPLATE_LANGUAGE=en
```

`WHATSAPP_TEMPLATE_LANGUAGE` is the language the **template was approved in**,
not the weaver's language. They are different things and conflating them is a
common cause of `132001` on an otherwise correct setup.

---

## Translating it later

The template above is English, and it is deliberately the only English a weaver
receives — everything after it (the captions carrying the saree name, the code
and the quantity) is generated by this application and already goes out in her
own language.

To translate the opening message too, submit **the same template name** with a
different language in WhatsApp Manager. Meta treats name + language as the key,
so `nerige_new_order` can exist in `en`, `kn`, `te`, `ta` and `hi`
simultaneously. Once they are approved, `WHATSAPP_TEMPLATE_LANGUAGE` can be
driven from `vendors.default_locale` instead of an environment variable — a
one-line change in `sendOrderOnWhatsApp`, deliberately left until the templates
actually exist, because sending against an unapproved language code fails the
same way as an unapproved name.
